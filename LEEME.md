# YosClau · sitio actual

Copia editable de las tres páginas públicas. Las versiones anteriores se mantienen en el historial del repositorio.

- `/`: inicio del toldo
- `/carpetas/`: Mis carpetas
- `/the-pixela-house/`: The Pixela House
- `/portafolio` y `/archivo/gafete/`: páginas necesarias para conservar enlaces de navegación

Abre la raíz del proyecto con un servidor estático. Las tres páginas, imágenes, videos y fuentes están en esta carpeta. Ningún servicio de alojamiento de Tab es necesario para cargar esas páginas.

Los enlaces intencionales a otros proyectos, redes sociales, Calendly y el proveedor del formulario conservan su destino original; no forman parte de este respaldo. No se debe cancelar un sitio de cliente o demo que se quiera seguir enlazando sin verificar su nuevo destino.

En Vercel: selecciona este proyecto como un sitio estático, con esta carpeta como raíz, prueba las tres entradas y los medios en el enlace de prueba antes de cambiar el dominio. No retires el alojamiento viejo hasta verificar lanzamientos y enlaces que se quieran conservar.
